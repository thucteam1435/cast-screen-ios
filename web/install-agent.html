Cài Cast Screen AirPlay Agent

Agent là thành phần Windows nhỏ chạy nền để PC Host nhận AirPlay trực tiếp từ iPhone trong mạng LAN. Bạn không cần cài Python và video/audio AirPlay không đi qua Cloudflare.

1. Tải bộ cài Windows chính thức của Cast Screen AirPlay Agent.
2. Cài đặt một lần. Agent có thể chạy nền cùng Windows.
3. Quay lại phòng Cast Screen. Khi Host tạo phòng, AirPlay Receiver mới được bật.
Lưu ý: Bộ cài Windows đang được chuẩn bị tự động từ source công khai của dự án. Khi chưa có artifact phát hành, trang này sẽ chuyển bạn tới trang phát hành để lấy bản chính thức.
