Đang tải Cast Screen AirPlay Agent…

Agent là thành phần Windows nhỏ chạy nền để PC Host nhận AirPlay trực tiếp từ iPhone trong mạng LAN. Bạn không cần Python và hình/tiếng AirPlay không đi qua Cloudflare.

1. File cài Windows sẽ được tải trực tiếp.
2. Mở CastScreenAirPlayAgentSetup.exe sau khi tải xong.
3. Cài một lần. Agent tự chạy nền cùng Windows.
Lưu ý: Bản phát hành hiện chưa có chứng thư code-signing nên Windows SmartScreen có thể cảnh báo file mới. Mã nguồn, bản build và SHA-256 được công khai trong dự án.
