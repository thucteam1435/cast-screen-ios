Cài Cast Screen AirPlay Agent

Agent là thành phần Windows nhỏ chạy nền để PC Host nhận AirPlay trực tiếp từ iPhone trong mạng LAN. Bạn không cần Python và hình/tiếng AirPlay không đi qua Cloudflare.

1. Bấm TẢI VÀ CÀI AGENT. File cài Windows sẽ được tải trực tiếp.
2. Mở file CastScreenAirPlayAgentSetup.exe và cài một lần.
3. Agent tự chạy nền cùng Windows. Quay lại phòng Cast Screen để nhận AirPlay.
Về cảnh báo Windows: đây là bộ cài Windows của Cast Screen AirPlay Agent. Vì bản phát hành chưa có chứng thư code-signing, SmartScreen có thể hiển thị cảnh báo cho file mới. Tài liệu nguồn và SHA-256 được phát hành cùng bản cài.
⬇ TẢI VÀ CÀI AGENT Quay lại Cast Screen

Bản tải trực tiếp ổn định: CastScreenAirPlayAgentSetup.exe · Nguồn mã: github.com/thucteam1435/cast-screen-ios
