Cast Screen AirPlay Agent

Đây là chương trình nền dành cho PC Host. Nó cho phép iPhone xuất hiện trong danh sách AirPlay và chuyển phiên AirPlay vào Cast Screen. Video/audio AirPlay đi trực tiếp trong mạng LAN; Cloudflare chỉ phục vụ giao diện web.

Agent làm gì?

Chạy UxPlay + mDNS khi bạn tạo phòng, mở receiver AirPlay trên PC, rồi tự tắt UxPlay khi phòng đóng. Agent không đọc mật khẩu, không ghi lại màn hình, và không cần Python sau khi cài.

1
Tải bộ cài Windows chính thức.
2
Cài CastScreenAirPlayAgentSetup.exe.
3
Quay lại Cast Screen và tạo phòng. Agent sẽ tự bật AirPlay.

Lưu ý: Bản repo hiện đã có pipeline build bộ cài Windows nhưng chưa có artifact phát hành công khai ổn định. Nút dưới mở trang build chính thức của repo; khi artifact được tạo, đặt file installer vào release để dùng link tải trực tiếp.

Kiểm tra file

Chỉ cài file có tên CastScreenAirPlayAgentSetup.exe từ kênh phát hành của Cast Screen. Khi có bản phát hành, SHA-256 của file sẽ được công bố cùng bản tải để đối chiếu.
